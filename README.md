# 🌐 Fleek - Social Media Website

Welcome to **Fleek**, a modern and simple social media web application built using **Django** and frontend technologies.  
This project is designed to simulate a basic social media platform where users can interact and share content.

---

## ✨ About the Project

**Fleek** is a Django-based social media website developed as part of learning and internship practice.  
It focuses on core social media features like posting, user interaction, and a clean UI experience.

---

## 🚀 Features

- 📝 Create and manage posts  
- 👤 User authentication system  
- 📱 Responsive and clean UI design  
- 🖼️ Image/text post support  
- 🔐 Secure Django backend  
- 💬 Basic social media interaction structure  

---

## 🛠️ Tech Stack

- **Backend:** Django (Python)  
- **Frontend:** HTML5, CSS3, JavaScript  
- **Database:** SQLite  
- **Template Engine:** Django Templates  

---
